# Aarambh Suntech Solution Professional Solar Website — Next.js

Built from the uploaded GraphiKrafts offer for the solar website project.

## Included
- Separate Home, About, Services and Contact pages
- Responsive professional solar-company design
- Scroll reveal animations
- Hero solar artwork
- Services for Solar, CCTV and Electrical Work
- Project gallery placeholders
- WhatsApp integration
- Quick-call integration
- Lead/enquiry form UI and success state
- Mobile navigation
- SEO-friendly semantic page structure
- Easy-to-replace logo/brand and project gallery

## Run
Install Node.js LTS, open this folder in VS Code, then:

npm install
npm run dev

Open:
http://localhost:3000

Production:
npm run build
npm start

## Before client launch
1. Replace SunGrid with the real client business name.
2. Replace the phone number and email.
3. Replace gallery placeholders with real project photos.
4. Connect the lead form to a real email/CRM/database.
5. Add final approved logo and banner artwork.
6. Add final business address/service area.
7. Configure .in domain and hosting.
8. Add production SEO metadata, sitemap, robots and analytics.
